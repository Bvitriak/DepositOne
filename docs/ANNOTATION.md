# Аннотация

## О проекте

**DepositOne** - это учебное full-stack веб-приложение для управления банковскими
вкладами. Проект выполнен студентом Богданом Витряком (группа ОКБИ-204Б) для
Московского Технологического Института.

Приложение представляет собой внутреннюю платформу сотрудника банка (оператора,
аналитика), которая закрывает полный цикл работы с депозитными договорами: от
регистрации карточки клиента до формирования графика возврата средств и просмотра
аналитики по портфелю.

## Проблема

Работа с вкладами в небольшом финансовом отделе часто ведётся в разрозненных
таблицах: данные о клиентах, суммах вкладов, процентных ставках и подписанных
договорах хранятся отдельно и не связаны между собой. Из-за этого возникают
типичные проблемы:

- дублирование данных о клиенте в нескольких местах;
- отсутствие единого расчёта процентов и сроков вклада;
- невозможность быстро оценить структуру портфеля и предстоящие выплаты;
- ручной поиск договоров, требующих подписания.

## Идея решения

DepositOne объединяет три главные сущности в одну связанную модель данных:

1. **Вкладчик (Depositor)** - карточка клиента с паспортными и контактными данными.
2. **Вклад (Deposit)** - открытый депозит, который принадлежит конкретному вкладчику.
3. **Договор (Contract)** - соглашение, которое оборачивает ровно один вклад.

Каждый вклад привязан к вкладчику, каждый договор привязан к одному вкладу, а план
возврата и отчётность выводятся из параметров вклада (сумма, ставка, срок). Такая
модель убирает дублирование и даёт единый источник правды для расчётов.

Поверх модели данных построены рабочие сценарии:

- **Аналитическая панель (Dashboard)** со сводкой по портфелю и диаграммами.
- **Отчёты (Report)** по денежным потокам и доходности вкладчиков.
- **План возврата (Return Plan)** с расписанием предстоящих выплат и приоритетами.
- **Уведомления** о ближайших выплатах и договорах, ожидающих подписания.

## Что делает приложение

- Регистрация и вход сотрудников с выдачей JWT токена.
- Полный набор CRUD операций над вкладчиками, вкладами и договорами.
- Поиск, фильтрация, сортировка и постраничная выдача на уровне запросов к базе.
- Автоматический расчёт срока вклада, начисленных и итоговых процентов.
- Пересчёт сумм в выбранную валюту (USD, EUR, RUB).
- Аналитическая панель с круговыми диаграммами на Highcharts.
- Отчёты по денежным потокам за период и по доходности вкладчиков.
- Публичная страница описания проекта и служебный эндпоинт хеширования строки.
- Резервные ответы, когда база данных или сервис недоступны.

## Технологический стек

| Слой | Технологии |
| --- | --- |
| Frontend | HTML, CSS, JavaScript, Highcharts |
| Сервис Core | Python, FastAPI |
| Сервис Supporting | Python, Flask |
| База данных | PostgreSQL 18, репликация Master-Slave |
| Авторизация | JWT |
| Доступ к данным | SQL без ORM |
| Инфраструктура | Docker, Docker Compose, Nginx |

## Роли в проекте

Проект охватывает две основные роли:

- **FullStack разработчик** - интерфейсы, серверная логика, API, интеграция
  фронтенда и бэкенда, выбор стека, контроль качества кода во всех слоях.
- **Database Engineer** - проектирование схемы и связей, нормализация, сложные
  запросы, триггеры, индексация и настройка репликации.

Подробное описание архитектуры, базы данных, API и сценариев использования
приведено в остальных документах папки [docs](.).
