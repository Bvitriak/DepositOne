# Руководство пользователя

Документ описывает работу с интерфейсом DepositOne по всем страницам и сценариям.

## Запуск и вход

1. Поднимите проект по инструкции из [README](../README.md) (Docker Compose).
2. Откройте `http://localhost:8080`.
3. На главной странице нажмите "Get Started" (регистрация) или "Welcome Back"
   (вход).

После входа токен доступа сохраняется в браузере. Защищённые страницы без токена
автоматически перенаправляют на страницу входа.

## Настройки интерфейса

- **Язык.** Переключается на странице профиля (English / Русский) и применяется ко
  всему интерфейсу.
- **Валюта.** Переключается на странице профиля (USD, EUR, RUB). Суммы
  пересчитываются на сервере по фиксированному курсу.

## Главная страница

Обзор возможностей платформы: аналитика, вкладчики, вклады, договоры, отчёты, план
возврата. Верхнее меню и подвал дают быстрый переход к разделам, странице About,
API и поддержке.

## Регистрация, вход и сброс пароля

- **Регистрация.** Укажите имя пользователя, email и пароль. После успешной
  регистрации выдаётся токен и открывается рабочая область.
- **Вход.** Email и пароль. Кнопка с иконкой глаза показывает или скрывает пароль.
- **Сброс пароля.** Сначала проверяется наличие аккаунта по email, затем задаётся
  новый пароль.

## Аналитическая панель (Dashboard)

Доступна по адресу `/dashboard` (защищена). Содержит:

- сводные карточки: число вкладчиков, число вкладов, активные вклады, стоимость
  портфеля, начисленные проценты;
- круговые диаграммы на Highcharts: распределение вкладов по статусам и структура
  портфеля по валютам;
- список топ вкладчиков с переходом в карточку.

Если сервис недоступен, показатели отображаются как `N/A`.

## Вкладчики (Depositor)

- **Список.** Поиск по имени, email, стране, адресу и дате рождения. Сортировка (по
  дате создания, имени, стране, дате рождения). Пагинация (10, 25, 50 на страницу).
- **Создание.** Имя, фамилия, дата рождения (кастомный календарь), страна,
  паспорт, ИНН, телефон, email, адрес. Возраст должен быть 18 лет и старше.
  Паспорт, ИНН и email уникальны.
- **Карточка.** Просмотр данных, число активных вкладов, дата открытия,
  редактирование и удаление. Удалить можно только вкладчика без вкладов.

## Вклады (Deposit)

- **Список.** Поиск по имени вкладчика, номеру вклада, статусу, валюте и сумме.
  Фильтр по статусу (Active, Pending, Closed, Blocked). Сортировка (дата, имя,
  сумма, ставка, дата окончания). Пагинация.
- **Создание.** Выбор вкладчика и валюты, статус, сумма, процентная ставка (0-100),
  даты начала и окончания (два календаря). Дата окончания должна быть позже даты
  начала.
- **Карточка.** Автоматический расчёт срока в месяцах, начисленных процентов на
  текущую дату, итоговых процентов и суммы к выплате. Удалить можно только вклад
  без договора.

## Договоры (Contract)

- **Список.** Поиск по номеру договора, номеру вклада, имени вкладчика, статусу
  подписания и дате. Фильтр по статусу (Signed, Pending, Rejected). Сортировка и
  пагинация.
- **Создание.** Выбор вклада (на один вклад - один договор), дата договора, статус
  подписания, описание и особые условия. Номер договора формируется автоматически.
- **Карточка.** Данные договора и связанного вклада, редактирование, удаление.

## Отчёты (Report)

Раздел показывает:

- карточки денежных потоков (Cash Flow) по периодам: сегодня, месяц, год, 5 лет
  (входящие, исходящие, остаток, чистый поток);
- поиск и список отчётов по вкладчикам с числом вкладов, суммой и доходом.

Суммы выводятся в выбранной валюте.

## План возврата (Return Plan)

- **Список планов.** Активные вклады с датой выплаты, суммой к возврату и ставкой.
  Поиск, сортировка, пагинация.
- **Сводка.** Итоги месяца (сумма к возврату, число возвратов, резерв ликвидности,
  выплаты завтра и на этой неделе) и приоритетные вклады по близости даты выплаты.
- **Карточка плана.** График начислений с капитализацией по месяцам и итоговой
  суммой возврата.

## Профиль `/<username>`

Страница профиля доступна по адресу `/<имя_пользователя>` и защищена.

- Карточка пользователя: идентификатор, ник, email, статус, дата создания, дата
  последнего входа.
- Сводка портфеля и операций по договорам.
- Переключатели языка и валюты.
- Блок JWT токена: кнопка "Release Token" выпускает новый токен, кнопка "Copy"
  копирует его в буфер обмена. Новый токен сразу становится активным.

## О проекте (About)

Страница `/about` показывает описание проекта, список возможностей, технологический
стек и метаданные (автор, группа, организация, версия, лицензия). Данные приходят из
`/api/about`. Если сервис недоступен, отображается встроенный резервный текст.

## Страница API

Список всех эндпоинтов приложения с методом, путём, областью (модуль), сервисом и
признаком защиты. Путь можно скопировать по клику.

## Поддержка (Support)

Публичная форма обращения. Кнопка "Send Ticket" открывает почтовый клиент с
подготовленным письмом на адрес поддержки (отдельного бэкенда у формы нет).

## Страница ошибки

Служебная страница показывает код ошибки из параметра `?code=`. На неё ведут
ответы `404` и `5xx` (недоступность сервиса или внутренняя ошибка). Ошибки
валидации (`4xx`) показываются прямо на форме.
